# ⚡ GAN 356 CUBE 3D & AI Solver (Кубик Рубика 3D + Решатель своего кубика)

Премиальный 3D симулятор кубика Рубика и AI-решатель реального кубика в стиле **GAN Cube** с управлением стрелками, желтым цветом сверху, белым снизу, свободным обзором на 360 градусов, вкладкой раскраски своего реального кубика, длинными 3D стрелками сборки и полным WCA скрамблом.

## 🚀 Основные режимы

### 1. 🎨 Вкладка «Собрать свой кубик» (AI Решатель)
- **Черный 3D кубик:** матовые черные наклейки для раскраски под ваш реальный физический кубик.
- **Цветовая палитра:** 6 официальных цветов GAN (Желтый, Белый, Зеленый, Синий, Оранжевый, Красный) + Ластик.
- **Интерактивные счетчики:** живой счетчик наклеек каждого цвета (должно быть ровно по 9 штук) с автоматической валидацией и отметкой `✓ 9/9`.
- **2D Развертка (Net View):** интерактивная панель развертки всех 6 граней. Раскрашивать можно как кликом по 3D кубику, так и в 2D развертке с мгновенной синхронизацией!
- **⚡ Двухфазный алгоритм Коциембы (min2phase):**
  - Моментальный расчет оптимального решения (в среднем не более 20-21 хода!).
  - Защита от физически невозможных состояний кубика (перекрученные углы, перевернутые ребра, ошибки паритета) с подсказками на русском языке.
- **📋 Полный скрамбл сборки (WCA Notation) для продвинутых спидкуберов:**
  - Располагается прямо сверху в красивом HUD-баннере с кнопкой `📋 Скопировать формулу`.
  - Подсветка активного хода в реальном времени.
- **🏹 Длинные 3D стрелки на гранях:**
  - Крупные светящиеся неоновые дуговые 3D стрелки через всю вращающуюся грань показывают точное направление вращения для каждого шага.
  - Пошаговые кнопки: `Вперед ▶`, `◀ Назад`, `▶ Авто-сборка` (с удобной паузой между ходами для повторения на реальном кубике).

### 2. 🎮 Вкладка «3D Симулятор»
- **Кубики:** 2x2, 3x3, 4x4, 5x5 и Пирамидка.
- **💎 Дизайн GAN Cube:**
  - Закругленные скошенные пластиковые тайлы (Beveled Tiles) с фирменным блеском.
  - Желтый цвет СВЕРХУ, Белый СНИЗУ, Оранжевый СПРАВА, Красный СЛЕВА.
  - Логотип GAN 356 M PRO на верхнем центре.
- **🎯 Управление стрелками:**
  - Стрелки на клавиатуре (`⬆️`, `⬇️`, `⬅️`, `➡️`) поворачивают выбранную грань в соответствующую сторону.
  - 3D стрелки прямо на ребрах при наведении курсора.
- **🔄 Свободный обзор на 360° и зум:**
  - Глубокое масштабирование и свободное вращение вокруг кубика.
  - Быстрые ракурсы граней: `🟡 Сверху`, `🟢 Спереди`, `🟠 Справа`, `🔴 Слева`, `🔵 Сзади`, `⚪ Снизу`, `3D Угол`.
- **🔀 Разборка и Сборка:**
  - «Разобрать» — честный скрамбл с широкими ходами для 4x4/5x5.
  - «Собрать» — пошаговое восстановление кубика.
- **⏱ Спидкубинг-таймер:** замер времени с сотыми долями секунды и сохранение персонального рекорда.

## 📦 Стек технологий
- Three.js r128 (3D WebGL движок)
- min2phase.js (WCA-стандартный Two-Phase Kociemba Solver)
- Web Audio API (звуковые эффекты магнитных щелчков GAN)
- Чистый JavaScript без сторонних фреймворков
