# 🎲 3D Rubik's Cube Simulator (Кубик Рубика 3D)

Интерактивный 3D симулятор кубика Рубика в браузере с **полным свободным обзором на 360 градусов**, **интерактивными стрелками на ребрах граней**, авто-решением и скрамблом.

## 🚀 Возможности

- **🔄 Свободный обзор на 360°:**
  - Зажмите и тяните в любой точке экрана, чтобы свободно вращать кубик под любым углом и видеть точное расположение всех деталей и наклеек со всех 6 сторон.
  - Панель быстрого переключения ракурсов: `Спереди (F)`, `Сзади (B)`, `Сверху (U)`, `Снизу (D)`, `Слева (L)`, `Справа (R)`, `3D Угол`.
- **🎯 Интерактивные стрелки на ребрах и гранях:**
  - При наведении курсора на стрелку подсвечивается весь слой, который повернется.
  - Стрелки показывают точное направление вращения: по часовой (↻), против часовой (↺) и направление сдвига ребер (⬆, ⬇, ⬅, ➡).
  - При клике на стрелку грань сразу же плавно поворачивается в выбранном направлении.
- **Разные виды головоломок:**
  - 2x2x2 (Карманный кубик)
  - 3x3x3 (Классический кубик Рубика)
  - 4x4x4 (Мастер-куб)
  - 5x5x5 (Профессорский кубик)
  - Пирамидка Мефферта (Pyraminx)
- **Отдельные кнопки действий:**
  - 🔀 **«Разобрать»** — случайный скрамбл с нотацией WCA и быстрой анимацией перемешивания.
  - ✨ **«Собрать»** — пошаговое авто-решение с плавной отмоткой ходов обратно и индикатором шагов.
  - 🔄 **«Сброс»** — мгновенный возврат в собранное состояние.
- **Таймер и спидкубинг:**
  - Замер времени (сотые доли секунды), счетчик ходов, сохранение рекорда (Best Time).
- **Звук и праздник:**
  - Механический щелчок при поворотах (Web Audio API).
  - Конфетти и фанфары при сборке.
- **Темы оформления:** Classic WCA, Neon Cyberpunk, Pastel.

## 📦 Локальный запуск

Откройте `index.html` в браузере или запустите сервер:

```bash
python -m http.server 8000
```
