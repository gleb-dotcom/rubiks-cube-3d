# 🎲 3D Rubik's Cube Simulator (Кубик Рубика 3D)

Интерактивный 3D симулятор кубика Рубика в веб-браузере с поддержкой множества головоломок, физикой поворотов граней, автоматической сборкой и разборкой.

## 🚀 Возможности

- **Разные виды головоломок:**
  - 2x2x2 (Карманный кубик / Pocket Cube)
  - 3x3x3 (Классический кубик Рубика / Rubik's Cube)
  - 4x4x4 (Мастер-куб / Rubik's Revenge)
  - 5x5x5 (Профессорский кубик / Professor's Cube)
  - Пирамидка Мефферта (Pyraminx)
- **Отдельные кнопки управления:**
  - 🔀 **Разобрать:** генерация случайного скрамбла с показом нотации WCA и анимацией перемешивания.
  - ✨ **Собрать:** плавное пошаговое авто-решение (отмотка ходов обратно к собранному состоянию) с отображением прогресса.
  - 🔄 **Сброс:** мгновенный возврат к исходному собранному состоянию.
- **Интерактивное управление:**
  - Вращение граней свайпом мыши / пальцем прямо по кубику.
  - Вращение камеры вокруг кубика перетаскиванием фона (OrbitControls).
  - Виртуальные кнопки граней (`U`, `U'`, `D`, `D'`, `L`, `L'`, `R`, `R'`, `F`, `F'`, `B`, `B'`).
  - Клавиатурные шорткоды: клавиши `U`, `D`, `L`, `R`, `F`, `B` (+ `Shift` для обратного хода), `Пробел` для таймера, `Ctrl+Z` для отмены.
- **Спидкубинг таймер:**
  - Замер времени сборки с точностью до сотых секунды.
  - Счетчик ходов и фиксация персонального рекорда (Best Time).
- **Звуковые эффекты и конфетти:**
  - Механический щелчок при повороте грани (Web Audio API).
  - Праздничный салют из конфетти и фанфары при сборке кубика!
- **Темы оформления:** Classic WCA, Neon Cyberpunk, Pastel.

## 🛠 Технологии

- HTML5 Canvas & WebGL
- [Three.js](https://threejs.org/) & OrbitControls
- Web Audio API (генерация звуков)
- Canvas Confetti
- Полностью адаптивный интерфейс без сторонних тяжелых фреймворков.

## 📦 Локальный запуск

Просто откройте файл `index.html` в любом современном браузере или запустите локальный сервер:

```bash
npx serve .
# или
python -m http.server 8000
```
